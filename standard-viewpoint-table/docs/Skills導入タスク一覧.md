## スタイル維持のチェックリスト（運用時）

- 各 `viewpoints/**/*.md` の観点一覧は、4列（機能 or 表示 / テスト観点カテゴリ / テスト項目 / 確認内容）を崩さない
- 編集履歴は必ず該当ファイルの**最下部**に、1観点あたり1行で追記
- 共通観点（00-共通から移植）のブロックは、既存と同じ見出し・表形式を維持
- 新規機能フォルダを増やす場合は、README の「機能別一覧」と `reference.md` の索引の両方を更新する
