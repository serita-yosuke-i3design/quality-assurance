# 検索・フィルタ（共通）

## 観点一覧

| 機能 or 表示 | テスト観点カテゴリ | テスト項目（観点） | 確認内容・期待値（具体的なテストポイント） |
| --- | --- | --- | --- |
| 表示 | レイアウト | レイアウト配置 | 検索フォームのレイアウトが適切か |
| 表示 | 画面項目 | 文字サイズ | 検索入力欄の文字サイズが適切か |
| 表示 | 画面項目 | 初期値（プレースホルダー） | プレースホルダーが適切に表示されるか |
| 表示 | 画面項目 | 表示・非表示 | 検索条件が適切に表示・非表示されるか |
| 表示 | 画面項目 | 活性・非活性 | 検索ボタン、クリアボタンの活性・非活性状態が適切か |
| 機能 | 入力制御 | IME制御 | 検索入力欄でのIME制御が適切か |
| 機能 | 入力制御 | Enterキー（確定と副作用） | 検索キーワード欄等で**Enter**を押下したとき、仕様が「**検索／絞り込みの実行**」である場合は、その**主アクションのみ**が実行され、誤った画面遷移・別フォーム送信・**二重検索**等の**意図しない副作用**がないか。仕様が「検索はボタンのみ」等でEnterにアクションを割り当てていない場合は、**入力値の確定**（IME確定・フォーカス移動等）に留まる、または何も起こさないなど、**意図しないアクション**が発生しないか |
| 機能 | 入力チェック | 必須チェック | 検索条件が必須かどうか |
| 機能 | 入力チェック | 桁数チェック | 検索キーワードの文字数制限が機能するか |
| 機能 | 画面操作 | 検索実行 | 検索ボタンで検索が実行されるか |
| 機能 | 画面操作 | クリアボタン | クリアボタンで検索条件がクリアされるか。クリアボタン押下で全入力が初期化され、一覧が全件表示の状態に戻るか |
| 機能 | 画面操作 | ドロップダウン選択 | チャット種別等のドロップダウン選択が機能するか |
| 機能 | 検索精度 | 部分/完全一致 | キーワードの一部、または全一致で期待通りのレコードが抽出されるか |
| 機能 | 検索精度 | 複数条件検索(AND) | 複数の検索条件を指定した際、すべての条件を満たすものだけが表示されるか |
| 機能 | 検索精度 | 検索結果表示 | 検索結果が正しく表示されるか |
| 機能 | 検索精度 | 検索結果なし | 検索結果がない場合の表示が適切か |
| 機能 | 検索精度 | 検索結果件数 | 検索結果件数が正しく表示されるか（該当する場合） |
