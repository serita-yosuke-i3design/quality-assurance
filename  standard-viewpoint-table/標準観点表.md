# 標準観点表（索引）

**正本は [viewpoints/](viewpoints/) のディレクトリ構成です。**

- **機能ID・機能カテゴリ** = フォルダ（例: `00-共通`, `01-ログイン`）
- **web or アプリ** = ファイル名（`共通.md` / `web.md` / `アプリ.md`）
- 各ファイルには**観点一覧**（機能 or 表示 以右の4列）と、**最下部に編集履歴**を記載。

一覧・検索は [README.md](README.md) の「機能別一覧」から該当ファイルへ。全観点の一覧は [標準観点表-統合版.md](標準観点表-統合版.md)。
