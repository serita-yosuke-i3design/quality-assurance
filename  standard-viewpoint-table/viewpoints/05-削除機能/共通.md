# 削除機能（共通）

## 観点一覧

| 機能 or 表示 | テスト観点カテゴリ | テスト項目（観点） | 確認内容・期待値（具体的なテストポイント） |
| --- | --- | --- | --- |
| 表示 | レイアウト | レイアウト配置 | 削除確認モーダル/ダイアログのレイアウトが適切か |
| 表示 | レイアウト | タイトル | モーダル/ダイアログのタイトルが正しく表示されるか |
| 表示 | 画面項目 | 文字サイズ | 確認メッセージの文字サイズが適切か |
| 表示 | 画面項目 | 表示・非表示 | 削除確認モーダル/ダイアログが適切に表示・非表示されるか |
| 表示 | 画面項目 | 活性・非活性 | 削除ボタン、キャンセルボタンの活性・非活性状態が適切か |
| 機能 | 画面操作 | 削除ボタン表示 | 削除アイコン/ボタンで削除確認モーダル/ダイアログが表示されるか |
| 機能 | 画面操作 | 二重確認（Alert） | 削除ボタン押下時、即座に消さず「本当に削除しますか？」等のダイアログが出るか |
| 機能 | 画面操作 | 削除実行 | 削除ボタンで削除が実行されるか |
| 機能 | 画面操作 | キャンセル | キャンセルボタンでモーダル/ダイアログが閉じるか |
| 機能 | データ削除 | 削除成功 | 削除が成功するか |
| 機能 | データ削除 | 削除エラー | 削除権限がない場合のエラーが表示されるか |
| 機能 | データ削除 | 削除後表示 | 削除後に一覧から削除されるか |
| 機能 | データ削除 | 物理/論理削除 | 削除実行後、一覧から消え、そのデータにアクセスしても閲覧不可になるか |
| 機能 | 権限 | 削除制限 | 自身のデータ以外、または権限がない場合に削除ボタンが非表示になっているか |
