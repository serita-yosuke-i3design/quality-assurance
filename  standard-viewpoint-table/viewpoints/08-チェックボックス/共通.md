# チェックボックス（共通）

## 観点一覧

| 機能 or 表示 | テスト観点カテゴリ | テスト項目（観点） | 確認内容・期待値（具体的なテストポイント） |
| --- | --- | --- | --- |
| 表示 | レイアウト | レイアウト配置 | チェックボックスの配置が適切か |
| 表示 | 画面項目 | 表示・非表示 | チェックボックスが適切に表示されるか |
| 表示 | 画面項目 | 活性・非活性 | チェックボックスの活性・非活性状態が適切か |
| 機能 | 画面操作 | チェックボックス操作 | チェックボックスをクリック/タップして選択/解除できるか |
| 機能 | 画面操作 | ラベルクリック | 文字部分をクリック/タップしてもチェックが反応するか |
| 機能 | 画面操作 | 全選択・解除 | 全選択ボタンの連動、および一部解除時の全選択ボタンの外れ方が正しいか |
| 機能 | 入力チェック | 最小/最大選択数 | 「2つ以上選択」等の制約がある場合、バリデーションが正しく機能するか |
| 機能 | データ登録 | 選択データ送信 | 選択したデータが正しく送信されるか |
