# ログイン（共通）

## 観点一覧

| 機能 or 表示 | テスト観点カテゴリ | テスト項目（観点） | 確認内容・期待値（具体的なテストポイント） |
| --- | --- | --- | --- |
| 表示 | レイアウト | レイアウト配置 | ロゴ、入力欄、ボタンの配置が崩れていないか |
| 表示 | レイアウト | タイトル | 画面タイトルが正しく表示されるか |
| 表示 | 画面項目 | 文字サイズ | 文字サイズが適切か |
| 表示 | 画面項目 | 文字の書式 | 文字の書式（太字、色等）が適切か |
| 表示 | 画面項目 | 初期値（プレースホルダー） | プレースホルダーが適切に表示されるか |
| 表示 | 画面項目 | 表示・非表示 | 必要な要素が表示され、不要な要素が非表示か |
| 表示 | 画面項目 | 活性・非活性 | ボタンの活性・非活性状態が適切か |
| 機能 | 入力制御 | IME制御・文字種 | ID/PW欄で適切なIME（半角英数等）が起動するか。スペース混じりの入力を許容するか |
| 機能 | 入力制御 | マスキング | パスワード入力内容が「●」や「＊」で隠されているか |
| 機能 | 入力制御 | コピー制御 | パスワードフィールドでコピー不可になっているか（該当する場合） |
| 機能 | 入力チェック | 必須チェック | 未入力時に、適切なバリデーションエラーが出るか |
| 機能 | 入力チェック | 桁数チェック | 最小・最大桁数外の入力時に、適切なバリデーションエラーが出るか |
| 機能 | 入力チェック | 文字種チェック | 許可された文字種のみ入力可能か |
| 機能 | 入力チェック | 形式チェック | メールアドレス形式等のチェックが機能するか |
| 機能 | 認証機能 | 正常系認証 | 登録済みの有効なID/PWでログインし、指定の初期画面へ遷移するか |
| 機能 | 認証機能 | 認証エラー（ID） | 存在しないIDを入力した際、ログインを拒否するか |
| 機能 | 認証機能 | 認証エラー（PW） | IDは正しいがPWが異なる際、ログインを拒否するか |
| 機能 | セキュリティ | エラー表示 | セキュリティ上曖昧なエラーを出すか（「IDまたはパスワードが正しくありません」等） |
| 機能 | セキュリティ | アカウントロック | 短時間に連続して失敗した場合、アカウントを一時ロックし、警告を表示するか |
| 機能 | 画面遷移 | 次画面遷移 | ログイン成功後の画面遷移が正しいか |
