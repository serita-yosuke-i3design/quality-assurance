## 1. 目的

機能ごとに「100% なら何ケースか」「削減後いくつか」を可視化し、`00_テスト計画書` §3 の品質方針と整合させる。

## 2. プロジェクト既定の組合せ方針

| ルール | 内容 |
| --- | --- |
| ベース | **2-way のみ** |
| 3-way | 高/高 または R1 で**検討**（採用 triple を機能別に列挙） |
| 100% | 原則不可（論理最大は説明用） |

## 2.1 見積の凡例（列）

| 列 | 意味 |
| --- | --- |
| 論理最大 | 因子値の全組合せ（上限。通常は採用しない） |
| 2-way 見積 | ペアワイズ covering array の目安 |
| 採用方針 | 2-way 基本 / 2-way + 3-way 検討（R1） |
| 採用見込 | 結合テスト手順ブロック目安 |
| 実 (n) | L4 集計。未実施時は − |
